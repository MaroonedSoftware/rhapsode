# Quick start

Two lines with Docker, and no checkout:

```bash
curl -fsSLO https://raw.githubusercontent.com/MaroonedSoftware/rhapsode/main/compose.yaml
docker compose up -d
```

The API answers on `http://127.0.0.1:8080` and the page on `http://127.0.0.1:8081`.
