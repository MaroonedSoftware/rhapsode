# rhapsode-engine-dia

Dia as a rhapsode engine.

Dia is Nari Labs' 1.6B dialogue model. It writes nonverbals where they happen, performing all eight
standard cues, and it was trained to produce two speakers in one pass. This package so far holds
what can be decided without the model: the tags, the speaker framing, and how text is cut into
pieces one generation reads well.
