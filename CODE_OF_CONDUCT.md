# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be considerate of the people you are talking to, argue with ideas rather than with people,
and accept that a maintainer may decline a change. Harassment, personal attacks and discriminatory
language are not tolerated in issues, pull requests, discussions or any other project space.

## Reporting

Report conduct that breaks this code to the maintainers privately, by contacting
[@robert-dean](https://github.com/robert-dean) or through GitHub's "Report content" menu on the
comment in question. Reports are kept confidential. The maintainers decide on a response following
the Contributor Covenant's enforcement guidelines, from a private warning to a permanent ban.
